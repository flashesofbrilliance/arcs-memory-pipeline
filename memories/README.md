# Track 1 — Memory Export

## What lives here
Snapshots of Perplexity account memories exported manually or via API (when available).

## Manual Export Steps
1. Open Perplexity → Settings → Personalize → Manage Memories
2. Copy all memory entries
3. Save as `memories/snapshot_YYYY-MM-DD.md`
4. Commit to this repo

## Suggested Format: `snapshot_YYYY-MM-DD.md`
```md
# Memory Snapshot — YYYY-MM-DD

## Category: work.projects
- [memory text here]

## Category: preferences
- [memory text here]
```

## Notes
- No native bulk export exists in Perplexity as of April 2026
- Space-specific memories are not separately segmented; export covers the full account
